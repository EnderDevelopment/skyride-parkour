# SkyRide Parkour

SkyRide Parkour is a thrilling Roblox game that combines the excitement of parkour with the unique experience of riding various cars. Players can explore different environments, each with its own set of challenges and obstacles. The game features a variety of cars, each with unique stats and abilities, allowing players to customize their experience. With a boost meter system, players can hover and perform jumps, adding an extra layer of strategy to the game. The game also includes a coin system and a car spinner, where players can unlock and purchase special cars using in-game currency or Robux.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Click on "File" in the top menu and select "Open Model".
4. Navigate to the downloaded project files and select the main file.
5. Once the project is open in Roblox Studio, click on "File" again and select "Publish to Roblox".
6. Follow the prompts to publish the game to your Roblox account.

## Use

1. Launch the game in Roblox.
2. In the lobby, use the portals to select an environment based on your level.
3. Choose a car from the available options. Higher-level cars have better stats and abilities.
4. Navigate through the obstacle course, using your car's abilities to overcome challenges.
5. Collect coins to unlock new cars and upgrade your current ones.
6. Use the car spinner to purchase special cars with Robux or in-game currency.
7. Try to complete the course as quickly as possible to improve your time.
